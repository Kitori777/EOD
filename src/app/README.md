# Warstwa aplikacji

Ten folder składa interfejs i zarządza stanem przestrzeni roboczej. Nie należy umieszczać tutaj obliczeń domenowych.

- `EyesOfOdin.tsx` — główny stan oraz połączenie widoków z mechanikami.
- `views/` — ekrany aplikacji.
- `settings/` — preferencje użytkownika i okno ustawień.
- `storage/` — zapis i odtworzenie przestrzeni roboczej.
- `i18n/` — teksty polskie i angielskie.
- `help/` — pomoc dostępna z interfejsu.
- `styles/` — wspólna warstwa wizualna.

Szukając sposobu liczenia wyniku, przejdź do odpowiedniego folderu w `../mechanics/`.
